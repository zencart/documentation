## Storefront and Admin Demo
[jeandret.com](https://jeandret.com/) is a working Zen Cart store running the latest public release, with sample products, customers and orders. Browse, add to the cart and check out (money order is the only payment method). Then explore the admin with username `demo` and password `demo1234`.

Use the bar at the top of the page to switch between the Bootstrap and Responsive Classic templates. The whole store resets every hour, so change anything you like. A few admin saves that could reach beyond the demo are disabled, and the page will tell you when that happens. Email is turned off, so please don't enter real personal details.

The store is rebuilt every week from the latest releases, and its home page lists exactly what's installed.

If you're looking for demos of the backend, please see [admin demos](/user/admin/demos/).
