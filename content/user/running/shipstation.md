Zen Cart is supported by [ShipStation](https://www.shipstation.com), which is a popular postage and label creation solution.  Some other options are discussed in the [shipping labels FAQ](/user/shipping/labels/).

The integration that Zen Cart users should use is the 
[ShipStation plugin from the plugins library](https://www.zen-cart.com/plugins/shipstation-usps-ups-and-fedex-shipping-module-vb1324).  The plugin that ShipStation themselves distribute is out of date and should not be used.
