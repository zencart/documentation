There are several options if you wish to use a CAPTCHA in your cart: 

## Google CAPTCHA 
[Google CAPTCHA](https://www.zen-cart.com/plugins/google-recaptcha-captcha-vb1455)
is a plugin that creates the familiar "I'm not a robot" checkbox.

![Google CAPTCHA](/images/google_captcha.png)

The checkbox is shown on the following pages: 
- Ask A Question
- Contact Us
- Create Account
- Write Review 

## Cloudflare Turnstile
[Cloudflare Turnstile](https://www.zen-cart.com/plugins/cloudflare-turnstile)
is another option.  

![Cloudflare Turnstile](/images/turnstile.png)

It protects the following pages: 
- Create Account
- Contact Us
