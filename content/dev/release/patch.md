## Steps to build a patch

- Create the patch as a zip file.
- Announce the availability of the patch by creating a post on the [Release Announcements](https://www.zen-cart.com/forums/9) subforum.  Add the zip to this post.  
- Update the relevant Known Bugs thread for the release being patched under [Upgrading Your Zen Cart](https://www.zen-cart.com/forumdisplay.php?10-Upgrading-Your-Zen-Cart).   Update the [known bugs](/user/about_us/known_bugs/) page with this link.
- Update the [Security Patch list](/user/security/security_patches/) and/or the  [Plugin Patch list](/user/security/plugin_patches/) as appropriate.  
- Update the [What's New with Zen Cart](/user/about_us/whats_new/) page.
